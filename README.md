# 驱动源 0.1.0

免费的 Windows 电脑驱动查询与下载工具。支持本机硬件检测，优先提供厂商中国区入口，下载无需注册的 HTTPS 安装包直链。

## Windows 启动

标签推送后，GitHub Actions 会构建 Windows EXE 并发布到 Releases。构建成功后，可以下载并运行 `DriverSource.exe`。以下为源码启动方式。

1. 安装 Python 3.10 或更新版本，保留安装器中的 Tcl/Tk 组件。建议使用 Python 3.12。
2. 下载仓库 ZIP 并解压整个目录，双击 `start-windows.bat`。
3. 在“本机硬件”点击“检测本机硬件”，查看设备型号、系统架构和硬件 ID。
4. 在“国内驱动源”搜索品牌或设备类别，打开官方支持页，选择适合设备型号及 Windows 版本的驱动。
5. 在官方页面直接下载，也可以复制 HTTPS 文件下载链接，在“下载文件”中粘贴并选择保存位置。

桌面程序使用 Python 标准库，无额外运行依赖。也可以在项目目录运行 `python desktop.py`。

## 已实现

- 20 个品牌或官方目录入口，包含联想、戴尔、惠普、华为、华硕、英伟达、AMD、英特尔、普联、爱普生等。
- Windows WMI 本机检测，无需管理员权限，设备信息保留在本机。
- 硬件 ID 复制和微软更新目录查询。
- HTTPS 文件下载、大小进度、未知大小提示、取消、错误提示和下载文件夹快捷打开。
- 下载使用临时文件，成功后再替换目标文件，失败时保留原有文件。保留 TLS 证书验证，拒绝重定向至 HTTP。
- 网页版本与桌面版本共用 `sources.js` 中的源目录。

## 来源和覆盖范围

“国内源”采用厂商公开的中国区、中文支持入口，实际安装包服务器和访问速度由厂商决定。微软目录和部分厂商全球站作为补充。暂未建立驱动安装包镜像，所有型号的可用性取决于厂商和微软的收录情况。

0.1.0 由用户在来源页选择适配版本。驱动下载器支持无需登录的 HTTPS 文件直链。需要登录、验证码或专用下载会话的文件，可以在来源网站的浏览器中下载。硬件扫描结果用于查询和核对型号。

## 网页版

在项目目录运行 `python -m http.server 8000`，浏览器打开 `http://localhost:8000`。网页支持品牌、类别和硬件 ID 查询，也能导入检测清单。

Windows PowerShell 中运行 `.\scan-drivers.ps1`，桌面会生成或更新 `driver-source-devices.json`。网页导入后在本地读取。主动打开微软搜索链接时，对应的查询关键词会发送给微软。

## 打包 Windows EXE

在 Windows 上安装 Python 3.12，运行 `build-windows.bat`。构建脚本在项目内创建独立环境并安装 PyInstaller，输出 `dist/DriverSource.exe`，打包后的程序无需安装 Python。

本仓库提供构建脚本。Windows EXE 构建和实机 WMI 检测需要在 Windows 上验证。

## 开发验证

下载器回归测试需 Python 与 OpenSSL，运行：

```sh
python -m unittest discover -s tests -v
```

测试使用本地 HTTPS 服务器和临时测试证书，覆盖完整传输、取消、截断响应、HTML 响应、重定向和证书验证。
